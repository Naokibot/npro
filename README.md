# Npro 1.2.1

Spigot 1.21.1 / Java 21 向けの Npoint ユーティリティプラグインです。

## 機能

- `/np` から Npro GUI を開く
- Npoint の残高確認・管理
- Npoint を使ったシュルカーボックス利用権
- `/sb` でメインハンドのシュルカーボックスを開く
- Npoint を使ったエンダーチェスト利用権
- `/ec` でエンダーチェストを開く
- RTP
- バイオーム検索
- Npro の管理者向け有効・無効切り替え
- 1日1回のログイン報酬

### デイリーログイン報酬

日本時間の日付ごとに最初のログインで 5 Npoint を付与します。ログイン報酬のチャットは FreeLife の `/rtp` カウントダウン風に、金色の `[FreeLife]` と黄色の本文で表示します。

```text
[FreeLife] <MCID>がログインしログイン報酬5ポイント受け取りました！！
```

同じ日にもう一度ログインした場合はポイントを追加せず、そのプレイヤーだけに次を表示します。

```text
[FreeLife] あなたはすでに報酬を受け取っています！
```

受取日は `data.yml` の `players.<UUID>.daily-reward-date` に保存されるため、サーバーを再起動しても維持されます。

## ビルドについて

1.1.0 の配布元 JAR には Java ソースが含まれていませんでした。既存機能を書き直して挙動を変えないよう、このリポジトリでは検証済み 1.1.0 JAR を baseline として保持し、1.2.1 で必要な最小差分だけを Java ソースとして追加しています。

```bash
./scripts/build-release.sh /path/to/spigot-api-1.21.1-R0.1-SNAPSHOT.jar
```

出力:

```text
build/libs/Npro-1.2.1-Spigot-1.21.1.jar
```

## コード方針

既存機能の挙動を変えず、読みやすい小さなメソッド、明確な名前、早期 return、必要最小限のコメントを使う構成にしています。不要な抽象化や生成的な説明コメントは置きません。
